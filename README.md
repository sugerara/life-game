# Conway's Game of Life

Canvas と Vanilla JavaScript だけで実装した、コンウェイのライフゲームです。ビルドツールや外部ライブラリは使用していません。

## 特徴

- Canvas 2D API によるグリッド描画（HiDPI ディスプレイ対応）
- 再生 / 停止・ランダム生成・クリアの操作ボタン
- セルをクリック、またはドラッグして初期状態を自由に編集可能
- 色モード切替（単色 / 年齢で色分け）。生き延びた世代数に応じて青から赤へ変化
- 盤面は上下左右がつながったトーラス（無限平面）として計算
- ウィンドウサイズに応じてグリッドを自動リサイズ
- ライト / ダークモードに自動対応（`prefers-color-scheme`）

## 動作環境

最新の Chrome（バージョン 151 以降推奨）を想定しています。ES クラスのプライベートフィールド、CSS ネスト、`oklch()` カラーなど、モダンな JavaScript / CSS の機能を使用しています。

## 使い方

ビルド不要の静的サイトです。任意の静的サーバーで `index.html` を配信してください。

```sh
npx serve .
# もしくは
python3 -m http.server 8000
```

ブラウザで表示後:

1. 盤面をクリック、またはドラッグしてセルを生存/死滅させます
2. 「再生」ボタンで世代の自動進行を開始し、「停止」で一時停止します
3. 「ランダム生成」でランダムな初期状態を生成します
4. 「クリア」で盤面を全消去します
5. 色モードのセレクトで「年齢で色分け」を選ぶと、新しいセルは青、長く生き延びたセルは赤で表示されます

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | ページ構造（Canvas・操作ボタン） |
| `style.css` | 見た目のスタイリング |
| `script.js` | エントリーポイント（DOM 要素の取得と `GameOfLifeApp` の起動） |
| `game-of-life.js` | 盤面状態・セルの年齢・ライフゲームのルールを管理する `GameOfLife` クラス（DOM 非依存） |
| `board-renderer.js` | Canvas への描画（色モード対応）とポインタ座標変換を担当する `BoardRenderer` クラス |
| `app.js` | UI イベントと上記 2 クラスを統合する `GameOfLifeApp` クラス |
| `tests/game-of-life.test.js` | `GameOfLife` クラスの単体テスト |
| `tests/index.html` | ブラウザでテストを実行して結果を表示するページ |

## 実装メモ

- `GameOfLife` クラスが盤面状態とライフゲームのルール（誕生・生存・過疎・過密）を管理します
- `BoardRenderer` クラスが Canvas への描画とポインタ座標 → セル座標の変換を担当します
- `GameOfLifeApp` クラスが UI イベント（ボタン操作・ポインタ操作・リサイズ）と上記 2 クラスを統合します
- セルの年齢は盤面と並列の配列で保持し（最大 255）、年齢から `oklch()` のパレット（16 段階、対数スケール）を引いて描画します。明度・彩度は CSS 変数でライト / ダークごとに切り替えます
- アニメーションループは `requestAnimationFrame` を使用し、1 秒あたり 10 世代のペースで進行します

## テスト

`GameOfLife` クラス（盤面ロジック）は DOM に依存しないため、ブラウザ・その他の JS 実行環境どちらでも実行できます。外部のテストフレームワークは使用していません。

ブラウザで実行する場合:

```sh
python3 -m http.server 8000
```

を起動し、`http://localhost:8000/tests/` を開くと結果がページと DevTools コンソールに表示されます。

ES モジュールを実行できる JS ランタイム（例: Node.js）がある場合は、直接実行することもできます。

```sh
node tests/game-of-life.test.js
```
